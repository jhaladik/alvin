🔬 ML Architecture

Deep Q-Network (DQN): PyTorch neural network (296K params) trained on human gameplay using offline DQN with reward-based learning. Predicts Q-values for each action representing expected future reward.

Deployment: Hosted on Hugging Face Spaces with 16GB RAM for real-time inference. Frontend sends 128-dim feature vectors, receives Q-values + action probabilities.

Model Architecture: 768-dim input → 256→256→128 hidden layers → 4 outputs (UP/DOWN/LEFT/RIGHT Q-values). Uses batch norm, dropout for generalization.

Training Data: Behavioral cloning from human gameplay + offline Q-learning updates. Learns both imitation and value estimation for optimal moves.

Exploration Strategy: Epsilon-greedy with configurable rate (default 20%). Balances exploitation (best Q-value) with exploration (random moves) for continuous learning.
